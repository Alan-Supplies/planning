## 프레퍼스 KDS 시스템 연동 개발 협업 요청

로보이츠 플랫폼에서 발생하는 주문을 프레퍼스 자체 KDS 시스템에서 안정적 수신이 필요합니다.

1. 주문 연동 방식
* 신규 주문을 Webhook 방식으로 전달 가능한지
* 또는 저희 서버에서 주문 조회 API를 호출해야 하는 구조인지
* 주문 변경/취소 이벤트도 별도로 전달되는지

2. 주문 데이터 스펙
- 주문번호, 
- 매장 식별값, 
- 주문 시간, 
- 메뉴, 
- 옵션, 수량, 
- 결제 금액, 
- 포장/매장/배달 등 서비스 타입 구분
- 요청사항 등 전달 가능한 필드


---
1. 장애 및 재처리 정책

* Webhook 전달 실패 시 재시도 정책
* 동일 주문 이벤트가 중복 전달될 수 있는지
* 주문 상태를 재조회할 수 있는 API 제공 여부

5. 테스트 환경

* 샌드박스 또는 테스트 매장 제공 가능 여부
* 테스트 주문 생성 방법
* 운영 반영 전 검수 절차

가능하다면 개발 미팅을 통해 양쪽 시스템 구조와 연동 범위를 먼저 맞춘 뒤, API 스펙과 테스트 일정을 확정하고 싶습니다.
