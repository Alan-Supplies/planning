# Slack 토큰의 워크스페이스와 채널 확인

Slack Web API 토큰은 일반적으로 하나의 채널에 귀속되지 않는다. 토큰은 앱의 봇 사용자(`xoxb-`) 또는
Slack 사용자(`xoxp-`)를 나타내며, 권한(scope)과 채널 참여 상태에 따라 여러 채널에 접근한다.

`scripts/inspect_slack_token.py`는 다음 정보를 읽기 전용 API로 확인한다.

- `auth.test`: 토큰의 워크스페이스와 사용자/봇
- `conversations.list`: 현재 토큰으로 볼 수 있는 공개·비공개 채널
- 각 채널의 `is_member`: 토큰 주체가 실제로 참여 중인지 여부

## 실행

토큰을 명령행 인자로 전달하면 셸 기록이나 프로세스 목록에 남을 수 있으므로 환경변수만 사용한다.

```bash
export SLACK_TOKEN='xoxb-...'
python3 scripts/inspect_slack_token.py
```

특정 채널만 확인:

```bash
python3 scripts/inspect_slack_token.py --channel '#general'
python3 scripts/inspect_slack_token.py --channel C0123456789
```

앱 설정이나 채널 조회 scope가 없다면 Slack 메시지에서 **링크 복사**를 선택하고, 링크만 이용해 채널 ID를
추출할 수 있다. 이 방식은 토큰이나 API 권한이 필요 없다.

```bash
python3 scripts/inspect_slack_token.py \
  --message-link 'https://workspace.slack.com/archives/C0123456789/p1234567890000000'
```

JSON 출력 또는 보관된 채널 포함:

```bash
python3 scripts/inspect_slack_token.py --json
python3 scripts/inspect_slack_token.py --include-archived
```

다른 환경변수 이름을 쓴다면:

```bash
export MY_SLACK_BOT_TOKEN='xoxb-...'
python3 scripts/inspect_slack_token.py --token-env MY_SLACK_BOT_TOKEN
```

## 필요한 권한

- 공개 채널 조회: `channels:read`
- 비공개 채널 조회: `groups:read`

권한을 앱에 새로 추가했다면 워크스페이스에 앱을 다시 설치해야 새 토큰 권한이 반영된다. 비공개 채널은
권한만으로 모두 보이지 않으며, 일반적으로 토큰 주체가 참여한 채널만 반환된다.

## 해석 시 주의점

- `xapp-`는 Socket Mode 등에 쓰는 앱 레벨 토큰이므로 이 도구의 조회 대상이 아니다.
- Incoming Webhook URL은 설치 시 선택한 채널과 연결되지만, URL 자체를 이용해 그 채널을 역조회하는
  API는 없다. Slack 앱 설정의 **Incoming Webhooks** 목록에서 확인해야 한다.
- 검색한 채널이 나오지 않으면 토큰이 다른 워크스페이스의 것인지, 필요한 scope가 있는지, 비공개
  채널에 앱/사용자가 초대되었는지 확인한다.
