API
- 완료
  `patch` /kds/orders/{order_id}/position-complete/{position}
- 취소
  `patch` /kds/orders/{order_id}/cancel
- 보류
  `patch` /kds/orders/{order_id}/hold/{on/off}
- 긴급
  `patch` /kds/orders/{order_id}/urgent/{on/off}
- 수정됨
  `patch` /kds/orders/{order_id}/modify/{of/off}
- 이전 단계로
  `patch` /kds/orders/{order_id}/revert/{position}
