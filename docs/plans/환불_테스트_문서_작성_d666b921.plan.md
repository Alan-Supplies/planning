# 환불 테스트 플로우 및 케이스 문서 작성

## 현재 환불 관련 구조 분석

### 환불 관련 필드 ([`orders.entity.ts`](src/entity/orders.entity.ts))

```typescript
isRefunded?: boolean      // 환불 여부
refundAmount?: number     // 환불 금액
refundedAt?: Date         // 환불 시간
```

### 환불 처리 방식
- **전용 환불 API 없음**: 현재 `PATCH /orders/:id`를 통해 환불 필드를 직접 업데이트
- **매출 집계 제외**: 환불된 주문은 `(order.isRefunded IS NULL OR order.isRefunded = false)` 조건으로 매출 집계에서 제외
- **환불 통계 집계**: [`daily-sales.repository.ts`](src/module/orders/daily-sales.repository.ts)의 `aggregateRefundByDate`에서 환불 데이터 집계
