# 11. 세트 단위 강도 컬럼 신설

> [전체 목차](README.md) · [통합 원문](../DB_구조_업그레이드_방안.md)

세션 1개 값으로는 보이지 않는 세트 후반 품질 하락을 볼 수 있게 하는 작업

## 무엇을 바꾸는가

세트 테이블에 강도 컬럼을 신설하고 값 없음을 허용 · 컬럼만 먼저 열고 입력 강제는 화면이 준비된 뒤

현행 — 강도는 세션 단위 1개 값 · 컬럼은 `user_exercise_session.rpe` · 자각 강도 1~10 정수 척도

|항목|실측(2026-08-21)|
|---|---|
|전체 세션|327,844건|
|강도 값이 있는 세션|188,095건(57.4%)|
|값 분포|1~10 전 구간 사용·최빈값 5(66,412건) ·기본값이 박힌 것이 아니라 회원이 실제로 고르는 값|

## 어떻게 바꾸는가

1. 세트 테이블에 강도 컬럼 추가 · 값 없음 허용

2. 척도는 세션과 같은 자각 강도 1~10으로 확정(2026-08-21) · 세트 컬럼도 세션과 동일한 정수 척도

3. 값의 정의를 규약 문서에 고정 — 회원마다 다르게 이해하면 비교가 성립하지 않음

4. 계산 우선순위 규칙 명문화 — 노력 충족 판정은 세트 강도 우선, 없으면 세션 강도 · 두 값이 공존하므로 규칙 없이는 화면마다 다른 답이 나옴 5. 입력 강제와 화면은 후속

자각 강도 1~10을 택한 이유 — 세션 값과 직접 비교·롤업이 가능함 · 세트 평균과 회원이 신고한 세션 값을 대조해 입력 신뢰도를 검증할 수 있고, 다른 척도 를 쓰면 이 대조가 불가능 · 회원이 이미 쓰고 있는 척도라 학습 비용이 없고 기존 18만여 건과 시계열이 끊기지 않음 여유 반복 수를 버리는 것은 아님 — 두 값은 배타적이지 않으므로, 추정 최대 중량 환산 정밀도가 필요해지는 시점에 컬럼을 하나 더 추가하면 됨 · 지금 하나 만 고른다면 이미 쌓여 있는 쪽

## 무엇이 좋아지는가

세트 후반 품질 하락을 볼 수 있음 — 세션 값 하나로는 "총량이 늘었는데 품질도 좋아졌나"를 구분할 수 없음 · 세트별 값이 있으면 첫 세트와 마지막 세트의 차이, 세트가 진행될수록 여유가 줄어드는 속도를 볼 수 있음 정체 원인을 유형으로 나눌 수 있음 — 같은 중량에서 강도가 오르는 패턴은 회복 부족, 강도가 낮은데 성과가 없는 패턴은 자극 부족 · 세션 값만으로는 이 구 분이 불가능해 정체를 "성장 없음"으로만 표시하게 됨 노력 충족 목표가 성립함 — 마지막 세트에 여유 반복을 2~3개 남기는 수준을 목표로 삼는 계산이 가능해짐 지금 열어두면 이후 기록부터 쌓임 — 강도는 소급 입력이 불가능한 값 · 화면이 나중에 준비되더라도 컬럼이 먼저 있으면 준비된 시점부터 즉시 수집 시작

## 주의

- 세트마다 강도를 기록하고 싶어 하는지 사용자 의견 취합이 선행 필요 — 운동을 많이 하고 운동기록을 자주 쓰는 회원이 세트 단위 강도 입력을 실제로 원 하는지 확인되지 않음 · 원하지 않는다면 컬럼은 열어두더라도 화면은 만들지 않는 편이 낫고, 세션 단위 값(현재 57.4% 수집)으로 유지하는 선택도 성립 함 · 구조 준비와 별개로 화면 설계 착수 전 의견 취합을 조사 항목으로 등록 입력 부담이 기록률을 깎을 수 있음 — 세트마다 값을 요구하면 기록 자체를 포기할 위험 · 마지막 세트만 묻는 방식 등 입력 범위는 의견 취합 결과와 화면 설계에서 결정

- 세션 값 수집률 57.4%가 기준선 — 세트 단위 수집률이 이보다 크게 떨어지면 화면 설계가 실패한 것으로 판정 가능 값 없음이 대부분인 기간에는 표본 편향 — 강도를 입력한 회원만 분석되므로 전체 대표성이 없음 · 리포트에 수집률을 함께 표시

- 세션 값과 세트 값의 합산 금지 — 척도는 같지만 단위(세션 1건 대 세트 여러 건)가 달라 섞으면 의미가 어긋남 · 계산 우선순위 규칙으로만 사용하고, 세 트 평균과 세션 값의 대조는 검증 목적으로만
