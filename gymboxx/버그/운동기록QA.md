# 운동기록 QA — TestFlight 2.3.26(891), 2026-10-12

출처: QA 채널 스레드 https://w1622455415-twy380170.slack.com/archives/C0AQJU4QMEG/p1791773047699289
QA 계정 user 52449, 세션 1000653. 중복 보고는 하나로 합쳤다.

## 원인 확인됨

1. 세션 초기화 — 진행 중에 과거 기록을 '오늘 운동으로 불러오기' 하면 로컬 세션이 통째로 지워진다.
-> 클라이언트. 처음 담은 운동이 서버에만 남아 16개 중복, 앱은 종료된 것처럼 보이고 플로팅 배너가 사라진다. 불러오기가 교체·기본값으로 들어간 보고도 같은 원인이다.
-> 수정 3건: 진행 중 불러오기 때 로컬 세션 유지(운동 선택 경로도 출석 ID 저장), 진행 중 세션은 캘린더·요약에서 숨김, 최소화 상태에서도 미니바 위치 복원.
-> 미션 미반영은 서버 end_at 이 비어 있어서다. 의도된 동작이다.

2. '1개 운동 추가하기' 무반응 → 대시보드에 누른 만큼 같은 운동이 추가됨.
-> 17:32:57~17:33:13 운동 추가 POST 가 dev 500 으로 12번 실패했다(17:30~17:34 dev DB 의 share_opened_at 컬럼 불일치, 지금은 해소). 클라이언트가 실패해도 로컬에 운동을 넣는다.

3. 과거 기록 편집에서 스트레칭 추가 후 '모두 완료 처리 후 종료'가 적용 안 됨.
-> 서버에는 완료와 세트가 저장돼 있다. 세트 완료 체크는 서버에 저장하지 않는 로컬 상태라 다시 열면 풀려 보인다. 클라이언트.

4. 같은 운동인데 과거 기구·세트가 프리필되지 않음(일부만 됨).
-> 서버는 과거 기록과 기구를 정상으로 내려준다. 로컬에 저장된 세트가 있으면 서버 기록을 무시하는 클라이언트 조건 때문이다.

## 수정됨

5. 과거 기록 편집 중 Live Activity 배너가 뜨고, 눌러도 이동이 이상하고, 편집 완료 후에도 남음.
-> 891 에서 수정. 편집 중에는 안 뜨고 종료하면 닫힌다.

## 확인 필요

6. 11개 종목으로 완료했는데 완료 후 19개, 선택한 적 없는 운동 추가, 실제 완료한 운동은 볼륨 0.
목표 상세는 달성률 100% 인데 '0개 미션 완료', 미션 상세에는 과거 편집 전의 직전 기록이 반영됨.
-> 아직 안 봤다. 1번 경로와 미션 집계(서버)를 함께 확인해야 한다.

7. 화면을 내렸더니 시간은 흐르는데 반투명해지고 아무것도 조작 안 됨(강제 종료 후 정상).
-> 1번의 투명 미니바가 화면 맨 위에 터치를 받는 채 남는 경로일 수 있다. 추정이다.

## 클라이언트·디자인

8. 과거 편집 상단 프로그레스바 상태가 헷갈림 -> 진한 빨강=세트 모두 완료, 반투명 빨강=현재 위치, 회색=미완료. 다음에 개선.
9. 운동 기록 상세에서 좌우 스와이프와 하단 좌우 버튼의 화면 전환 속도가 다름.
10. 마지막 운동에서 스와이프로는 운동 종료가 안 뜨고 하단 화살표로만 뜸 -> 같게 동작해야 함.
11. 출석 안 한 상태에서 '운동 기록하기'를 누르면 나오는 안내를 더 잘 보이게 (Rothy).
12. Live Activity 세트 완료 해제 반영이 늦고, 체크 버튼을 눌러도 회차만 오를 뿐 완료 피드백이 약함 (Rothy).
13. 운동 공유 사진에 dim 처리 필요 -> 프리셋별 기본 필터 누락분 정리해 전달 예정 (Harvey).
14. 운동 공유 사진 선택에서 동영상도 선택됨.
15. 운동 목표 설정 첫 화면에 뒤로가기 없음 -> 강제 진입이 의도(Rothy). QA 는 일정 단계 전까지는 뒤로 나갈 수 있어야 한다는 의견. 결정 필요.
