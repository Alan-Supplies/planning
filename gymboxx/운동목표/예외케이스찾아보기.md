1. 목표 생성 당일, 생성 전에 끝낸 운동은 0으로 잡힌다. -> 당연하다고 생각한다.
2. 세션 종료를 안 누르면 영영 반영되지 않는다. -> 당연하다고 생각한다.
3. 기존 목표를 버리고 새 목표를 생성했을 때 지금까지 했던 수행이 버려지게 된다.
-> 목표별 미션은 의도가 뚜렸하다.
4. 시간을 안 적은 유산소는 0분이다. -> 유산소는 모두 시간이 들어갈 예정
5. 세부 부위 매핑이 없는 운동의 세트는 어느 미션에도 안 들어간다.
-> 이건 다시 봐야 한다.
6. 8종을 다 채워도 아무 신호가 없다 -> 의도된 것이다.
7. 지난 목표의 미션 상태 CLOSED 가 프론트 가이드에 없다.
-> 현재 CLOSED, ENDED 가 섞여 있어서 문제가 된다.
8. 성별·생년월일이 없는 회원은 목표 기능에 못 들어간다. -> 이미 반영함
9. 생성 버튼 더블클릭으로 중복 목표 생성될 수 있다. -> API에서 처리하기로함
10. 세션 종료가 날을 넘어갈 때 목표달성 반영 날짜가 종료 기준으로 된다. -> 시작시간으로 처리
