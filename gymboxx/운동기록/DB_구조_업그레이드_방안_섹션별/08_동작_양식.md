# 08. 동작 양식을 6번째 분류 축으로 선언

> [전체 목차](README.md) · [통합 원문](../DB_구조_업그레이드_방안.md)

이미 273종 전건 채워진 동작 양식 값을 정식 분류 축으로 승격하는 작업

## 무엇을 바꾸는가

`exercise.movement_pattern` 컬럼을 정식 분류 축으로 선언 · 스키마 변경 없음 · 현재는 "참고값"으로 취급되어 관리 대상에서 빠져 있음 현행 값 8종은 273종 전건 채워져 있고 열거형임 — 밀기 42 · 당기기 40 · 스쿼트 18 · 런지 12 · 힌지 22 · 단관절 114 · 이동 14 · 신장 11

## 어떻게 바꾸는가

1. 분류 규약 문서에 축 지위 명시 — 판정 질문은 "신체가 어떻게 움직이는가"

2. 이완 판정의 정본을 이 축으로 고정

3. 신규 운동 등록 필수 항목에 포함

4. 오분류 1종 정정 — 덤벨 사이드밴드의 값이 신장으로 잘못 부여됨

## 무엇이 좋아지는가

이완 판정이 일관됨 — 현재 폼롤링류를 찾는 조건이 세 가지이고 결과가 전부 다름

|조건|결과|내용|
|---|---|---|
|부위 라벨이 스트레칭|7종|폼롤링만|
|성격 태그가 이완|18종|폼롤링 0종·스쿼트·플랭크 등 근력 종목이 들어옴|
|동작 양식이 신장|11종|폼롤링 7 + 웜업 3 + 오분류 1|

셋의 교집합이 공집합이며, 부위 라벨 7종은 동작 양식 11종에 완전히 포함됨(7/7) · 동작 양식을 정본으로 고정하면 조건 하나로 일관된 답이 나옴 같은 부위 안에서 중복 추천을 막을 수 있음 — 가슴 종목 32종이 밀기 25종 + 단관절 7종 · 부위만 보면 32종이 모두 "가슴"이라 구별되지 않아 추천 5종이 전부 프레스류가 될 수 있음 · 축이 있으면 밀기 3 + 단관절 2로 분산하는 규칙이 성립

대체 종목 제안이 정확해짐 — 기구 점유 시 같은 부위 + 같은 동작 양식으로 대체

|상황|동작 양식 축 사용|부위만 사용|
|---|---|---|
|머신 체스트 프레스(밀기·가슴)점유|덤벨 벤치 프레스(밀기·가슴)|덤벨 체스트 플라이(단관절)도 후보—동작·부하가 다름|
|랫풀다운(당기기·등)점유|시티드 로우(당기기·등)|데드리프트(힌지·등)도 후보—대체 불가|

순발력( **`PLYOMETRIC`** ) 태깅을 서둘러야 할 이유가 없어짐 — 버피·점핑잭·스플릿 점프를 런지·스쿼트 + 점프 동작으로 식별할 수 있어, `functional_tag` 에 값을 열어둔 뒤 실제 태깅은 뒤로 미룰 수 있음

비용이 0 — 값이 이미 전건 채워져 있고 열거형이라 데이터 작업도 오분류 1종뿐
