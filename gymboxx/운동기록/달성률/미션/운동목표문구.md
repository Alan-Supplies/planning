## 0. 목적과 설계 기준

### 0-1. 목적·목표

| 항목 | 내용 |
| -- | -- |
| 목적 | 사용자가 운동할 이유를 구체화하고 계속 떠올려서 끝까지 운동하도록 유도 |
| 목표 | **연령·성별에 맞는 공감할 수 있는 목표 문구**를 선택지로 제공 |
| 사용자 선택 | 문구 **1개만 선택** · 미션은 생성 시스템이 자동 부여 — 선택 마찰 최소화("복잡하면 시작 전에 포기") |
| 목표 완료 | 사용자가 `완료` 버튼 클릭 · 게이지 없음 — 상세는 달성률 계산 시스템 §6 |

### 0-2. 문구 설계 기준

| # | 기준 |
| -- | -- |
| 1 | **생활형 언어** — 변화된 내 모습을 사용자의 말로 표현 · 지표·수치 표현 금지 |
| 2 | 목적 5종 순서 통일 — 다이어트 → 근력 → 건강 → 체력 → 자세 |
| 3 | 세그먼트 공감 축 반영 — 8세그먼트별 사회 특성(§12) 근거 |
| 4 | **전 문구가 미션 생성 가능** — 문구 추가·수정 시에도 목적 코드로 미션이 생성되는 구조 필수 |
| 5 | 하드코딩 금지 — **목표 마스터 테이블**(문구 · 목적 코드 · 세그먼트 · 노출 규칙)로 관리 · 새 문구 = 마스터 행 추가 |
| 6 | 결과 지표 문구 금지 — 체중·1RM 같은 결과는 문구의 정서적 표현으로만 사용하고 계산 대상으로 두지 않음 |

### 0-3. 설정 화면 진입 경로

| 회원 구분 | 진입 시점·위치 |
| -- | -- |
| 무료 회원 | **멤버십 결제 완료 이후** — 결제 전에는 목표 설정 불가 |
| 유료 회원 | **홈 화면 또는 마이페이지** |

### 0-4. 목표 상태 조작

| 조작 | 가능 시점 | 결과 |
| -- | -- | -- |
| **완료** | 언제든 · 미션 달성 여부와 무관 | 확인 팝업 → 히스토리로 이동 · 이후 **내역 확인만** 가능 |
| **변경** | 언제든 | 기존 목표는 **히스토리로 이동** · 연결된 **미션 수행 내용은 살아 있음** |
| **삭제** | 언제든 | 연결된 **미션 수행 히스토리도 같이 삭제** |
| **불러오기** | **미완료 목표만** | 히스토리의 미완료 목표를 다시 활성으로 가져옴 · 남아 있던 미션 진척을 이어받음 |

* **변경과 삭제의 차이가 핵심** — 변경은 기록을 남기고, 삭제는 기록까지 지움
* **활성 목표는 항상 1개** — 불러오기를 하면 기존 활성 목표가 히스토리로 이동

> ⚠️ **구현 시 주의** — `불러오기`는 PO 논의 후 **없애기로 확정**됐고 `삭제`의 최종 처리 방식은 미확정이다. 원문(TECH-601)에는 4종이 그대로 남아 있으니 [미션생선시스템_주의.md](미션생선시스템_주의.md) §4를 함께 확인할 것.

**완료 처리 상세**

| 항목 | 내용 |
| -- | -- |
| 조작 | 목표 문구 옆 `완료` 버튼 탭 → **확인 팝업**("정말 완료할까요") → 확정 |
| 판정 주체 | **사용자 본인** — 시스템 계산·자동 판정 없음 |
| 표시 | 문구 + 완료 버튼 · **게이지·진척 % 없음** · 완료 / 미완료 이진값 |
| 시점 | 사용자 임의 — 시스템이 유도·질문하지 않음 |
| 미션과의 관계 | **무관** — 미션 0%에서도 완료 가능 · 미션이 100%에 닿아도 목표 완료를 자동 처리하지 않음(그 미션의 교체 선택지가 열릴 뿐) |
| **되돌리기** | **불가** — 완료 목표는 재활성 대상이 아님 · 오조작은 확인 팝업으로 방어 |

**왜 사용자가 판정하는가**

| # | 내용 |
| -- | -- |
| 1 | 미션 = **행동** · 목표 = **결과** — 결과는 식단·수면 등 운동 외 변수가 좌우 |
| 2 | 미션 100% 수행에도 목표 미달 가능 — 정밀한 미션 설계로도 제거 불가 |
| 3 | 괴리를 숨기면 "시키는 대로 다 했는데 안 됐다" → 시스템 신뢰 붕괴 → 이탈 |
| 4 | 판정 주체를 사용자로 두면 시스템·사용자 간 기대 불일치가 구조적으로 소멸 |

### 0-4-1. 목표 히스토리

| 항목 | 내용 |
| -- | -- |
| 담기는 목표 | 완료 처리된 목표 · 변경으로 밀린 목표 · 불러오기로 밀린 목표 |
| 노출 단위 | 목표별 **완료 여부** + 그 목표에 연동된 **미션 달성률을 미션 단위로** 표시 |
| 예 | `A 목표 · 완료` → 가슴 100% · 코어 62% · 유산소 100% · 스트레칭 45% |
| 미션 교체 이력 | 같은 목표에서 미션이 교체된 경우 슬롯별로 이력 보존 — 100% 채우고 교체한 미션도 전부 노출 |
| 완료 목표 | **내역 확인 전용** — 재활성 불가 |
| 미완료 목표 | **불러오기로 재활성 가능** — 미션 진척을 이어받음 |
| 삭제된 목표 | 히스토리에 남지 않음 · 연결 미션 진척도 함께 삭제 |
| 저장 | 목표 행에 완료 시각 · 미션 진척 행은 목표 삭제 시에만 함께 삭제 |

### 0-5. 개인화 푸시 메시지 고도화 파트

**개입 방식은 이 문서에서 정하지 않음** · 푸시 메시지 개인화 고도화 작업의 입력으로 상황만 정리

| # | 상황 | 관찰되는 것 | 해석 |
| -- | -- | -- | -- |
| 1 | 미션 전부 100% · 목표 장기 미완료 | 세트가 2~3회 전진했는데 완료 클릭 없음 | 운동 외 변수(식단·수면) 개입 가능 |
| 2 | 미션 낮음 · 목표 완료 | 달성률 20%에서 완료 클릭 | 기록 누락 또는 외부 활동 · 목표 눈높이가 낮음 |
| 3 | 미션 정체 · 목표 미완료 | 일정 기간 달성률 변동 없음 | 이탈 위험 |
| 4 | 특정 미션만 정체 | 가슴은 교체를 3번 했는데 스트레칭 0% 고착 | 그 미션이 회원 습관과 불일치 — 유형 재검토 신호 |
| 5 | 미션 초과 편중 | 한 미션 200%+ · 나머지 저조 | 같은 운동만 반복 · 구성 규칙 재검토 신호 |
| 6 | 목표 잦은 교체 | 완료 없이 목표만 반복 변경 | 문구 적중률 문제 |

* 카피 작성 시 문구 금지 규칙 준수 필요 — 효과 단정·질책 톤 금지
