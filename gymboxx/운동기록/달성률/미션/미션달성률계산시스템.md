## 1. 계산 대상

| 대상 | 정의 | 계산 여부 |
| -- | -- | -- |
| **운동 목표** | 목표 문구 — 변화된 내 모습의 언어 (예 `입고 싶던 옷 편하게 입기`) | ❌ 계산 없음 — 완료 여부는 사용자 `완료` 클릭 |
| **미션** | 부여된 운동 1건 — 축 값 + 볼륨 (예 `가슴 40세트분`) · 슬롯 최대 5개에 동시 진행 | ✅ **계산 대상** — 미션마다 개별 |

* **종합 달성률 없음** — 미션 5개를 합산·평균하는 지표가 존재하지 않음 · 미션 1개 = 게이지 1개
* 슬롯마다 미션의 부여 시각이 다를 수 있음 — 계산은 **미션별 부여 시각 이후**의 기록만 누적
* 부여 경로와 무관하게 **동일 엔진** — 문구 선택도, 기타 서술형도 목적 코드로 미션이 부여되므로 계산 케이스가 갈리지 않음
* 미션 볼륨과 구성은 계산 시점에 이미 확정된 입력값 — 이 문서는 그 값을 받아 나누는 일만 다룸

## 2. 계산 원칙

| # | 원칙 | 내용 |
| -- | -- | -- |
| 1 | 미션별 독립 | 미션 간 계산 관계 없음 · 한 미션의 초과가 다른 미션의 부족을 보완하지 않음 |
| 2 | 절대 총량 | 미션 볼륨은 기간 없는 총량 · 기간 마감·일할 비례·자정 경계 없음 |
| 2-1 | 미션별 기산점 | 분자는 그 미션이 슬롯에 부여된 시각 이후 기록만 — 교체 전 초과분 이월 없음 |
| 3 | 총량 인정 | 회당 기준 미달 기록도 전부 총량으로 누적 · `유산소 360분` 미션에 15분 × 12회 수행 = 180 ÷ 360 = **50%** |
| 4 | 초과율 표시 | 분자가 분모를 넘으면 실제 비율 표시(예 200%) · 캡으로 잘라내지 않음 |
| 5 | 기록 기반 | 미션 전부 운동 기록 원천 — 미기록 시 0% · 출입만으로 오르는 미션은 폴백 세트의 `운동한 날` 뿐 |
| 6 | 이벤트 기반 | 운동 기록 종료 시점 즉시 재계산 · 배치 없음 |
| 7 | 전량 재산출 | 누적 가산이 아니라 원천 전체 재집계 — 중복·수정·삭제 이벤트에도 항상 정답 |
| 8 | 결과 지표 제외 | 체중·1RM 같은 결과는 계산 대상 아님 — 운동량과 결과의 관계가 개인차 커서 행동만 계산 · 결과는 추이로만 표시 |

### 2-1. 정확도의 눈높이

| # | 내용 |
| -- | -- |
| 1 | 달성률은 의학·스포츠 과학적 정밀 측정이 아니라 **목표 달성 과정을 숫자로 전환하는 장치** |
| 2 | 예 — `근력 10회` 미션에서 2회 수행 시 그 미션은 **20% 달성** |
| 3 | 단 산식의 뼈대(분·세션 수·세트분)는 WHO·ACSM 등 공식 가이드라인과 정합 유지 — **근거 없는 수치를 만들지 않는 선** |

## 3. 계산 입력 — 미션 데이터 구조

슬롯 4개에 `가슴 40세트분` · `코어 40세트분` · `유산소 360분` · `스트레칭 90분`이 부여된 경우

| 필드 | 미션 ① | 미션 ② | 미션 ③ | 미션 ④ |
| -- | -- | -- | -- | -- |
| `slot_no` | 1 | 2 | 3 | 4 |
| `axis` | 부위 | 부위 | 성격 | 성격 |
| `metric_type` ⬜ | `BODY_PART_SET` | `BODY_PART_SET` | `CARDIO_MINUTE` | `STRETCH_MINUTE` |
| `target_total` (분모) | 40 | 40 | 360 | 90 |
| `target_param` | 부위 = 가슴 | 부위 = 코어 | — | — |
| 표시용 원문 | `가슴 40세트분` | `코어 40세트분` | `유산소 360분` | `스트레칭 90분` |

* `slot_no` 범위 **1~5** · 종합 행 없음
* `target_total`은 그 미션이 부여된 시점의 **스냅샷** — 이후 마스터·기준 테이블 변경의 소급 없음
* 슬롯별로 부여 시각(`assigned_at`)을 보유 — 분자 집계의 기산점
* ⬜ `metric_type` 명명은 DB 구조 개편 작업에서 확정 · 위 값은 잠정 표기

> ⚠️ **구현 시 주의** — 스냅샷은 마스터 FK 참조가 아니라 **계산된 최종값을 복사 저장**한다. `templateId`는 추적용으로만 남기고 조회 시 마스터를 다시 조인하지 말 것. 엔티티 네이밍은 `MemberMission` 확정 — [미션생선시스템_주의.md](미션생선시스템_주의.md) §3·§5.

## 4. 분자 산식 — 미션 유형별 7종

**공통 필터** — 해당 회원 · **그 미션의 부여 시각 이후** · 종료된 세션(`end_at IS NOT NULL`) · 삭제 세션·INACTIVE 운동 제외 · 외부 운동(`source='OUTSIDE'`) 포함

| 미션 유형 | 분자 계산 | 필요 데이터 축 |
| -- | -- | -- |
| 성격 — 유산소 분 | 시간 측정 유산소 종목 세트의 분 누적 · 강도 환산 = 중강도 분 + 고강도 분 × 2 | 성격 축(`MODALITY`) · 유산소 강도 컬럼 |
| 성격 — 스트레칭 분 | 스트레칭 종목(성격 축)의 분 누적 | 성격 축 · 시간 측정 항목 |
| 성격 — 근력 세션 | 근력 성격 종목을 1개 이상 포함한 세션 수 | 성격 축 파생(근육 부위 라벨 보유) |
| 부위 — 세트분 | 완료 세트 × 부위 기여도 합산 — 직접 1.0 / 보조 0.5 | 세부부위 기여도 |
| 부위 — 총 훈련량 | 해당 부위 직접 종목 세트의 **무게 × 반복 수 합** | 환산 무게 · 반복 수 · 부위 기여도 |
| 효과 — 세션 수 | 해당 효과가 **주 효과**인 종목을 1개 이상 포함한 세션 수 | 효과 축 테이블 · 주 효과 구분 |
| 운동한 날 | 기록이 있는 서로 다른 한국시간 날짜 수 — 하루 2세션도 1일 | 세션 날짜 |

### 4-1. 부위 세트분 — 세부부위 합산

| 층위 | 내용 |
| -- | -- |
| 기본 동작 | 세부부위가 달라도 상위 부위가 같으면 합산 — 윗가슴·중간가슴 운동 모두 `가슴` 미션 실적으로 계상 |
| 합산 방식의 고유 지점 | **한 운동의 한 세트**가 같은 부위의 세부부위 여러 곳에 동시 기여하면 전부 합산 — 1세트가 1세트분 초과 가능 |

계산 예 — `가슴 40세트분` 미션

| 운동 | 수행 | 가슴 기여도 매핑 | 가슴 실적 |
| -- | -- | -- | -- |
| 머신 체스트 프레스 | 4세트 | 중간가슴 직접 1.0 | 4 × 1.0 = **4.0세트분** |
| 덤벨 인클라인 벤치 프레스 | 4세트 | 윗가슴 직접 1.0 + 중간가슴 보조 0.5 | 4 × 1.5 = **6.0세트분** |
| 합계 | 8세트 수행 | — | **10.0세트분** → 40세트분 대비 25% |

* 수행 8세트 ≠ 표시 10.0세트분 — 이 인지 차이를 흡수하기 위해 단위 표기 `세트분` 통일
* 다른 부위 기여(예 삼두 보조 0.5)는 팔 미션에만 계상 — 가슴 미션 미포함
* 대안이었던 "세트당 부위 최대 기여도" 방식(한 세트는 한 부위에 최대 1세트분)은 수행 세트 수와 일치하나 볼륨 산정 근거와 불일치로 **미채택** · 재검토 트리거 — "숫자가 이상하다" 관련 CS 발생률

## 5. 달성률 산식

```text
미션별:        rate_i = 분자_i ÷ target_total_i     (캡 없음 — 100% 초과 시 실제 비율)
교체 가능 판정:  rate_i ≥ 1.0  →  그 슬롯에 교체 선택지 개방
```

| 항목 | 내용 |
| -- | -- |
| 합산 산식 | 없음 — 미션 간 평균·합계를 구하지 않음 |
| 교체 가능 판정의 용도 | 미션별로 판정해 생성 시스템에 전달 → 그 슬롯의 `새 미션 받기` 개방 · 교체 실행은 사용자 선택 |
| 미달 미션 | 100% 미달 상태에서는 교체 판정이 서지 않음 — 생성 시스템의 교체 요청도 거부 |
| 반올림 | 표시는 정수 반올림 · 저장은 소수 보존 |

### 5-1. 계산 예 — 세션 2건 진행 후

동시 진행 미션 — `가슴 40세트분` · `코어 40세트분` · `유산소 360분` · `스트레칭 90분`

| 세션 | 실적 |
| -- | -- |
| 1회차 | 가슴 12세트(직접 1.0) · 코어 8세트(직접 1.0) · 트레드밀 걷기(중강도) 40분 · 폼 롤링 10분 |
| 2회차 | 가슴 10세트 · 인터벌 런(고강도) 20분 |

| 미션 | 분자 | 달성률 |
| -- | -- | -- |
| 가슴 40세트분 | 12 + 10 = 22.0세트분 | **55%** |
| 코어 40세트분 | 8.0세트분 | **20%** |
| 유산소 360분 | 40 + 20 × 2 = 80분 | **22.2%** |
| 스트레칭 90분 | 10분 | **11.1%** |

* 가슴만 한 2회차는 **가슴·유산소만 상승** · 코어·스트레칭은 그대로 — 서로 영향 없음
* 하루에 가슴 80세트를 하면 가슴 미션은 **200%**로 표시 · 100%를 넘긴 시점부터 그 슬롯에 교체 선택지가 열림 · 나머지 3개는 영향 없음

## 6. 계산 시점과 저장

| 항목 | 내용 |
| -- | -- |
| 트리거 | 운동 기록 종료·수정·삭제 즉시 + 미션 부여·교체 시 + 목표 변경·삭제·완료 클릭 시 |
| 재계산 범위 | 해당 세트의 원천 전체 재집계 |
| 저장 | 미션별 1행(`slot_no` + 슬롯 회차) · 홈 조회는 저장값 반환 · 재집계 없음 |
| 상태 | `IN_PROGRESS`(live 갱신) → 100% 도달 시 `CLEARED`(교체 선택지 개방 · 초과율은 계속 갱신) → 사용자 교체 시 `REPLACED` · 목표 완료·변경·삭제 시 `CLOSED` |
| 이력 | 교체·종료된 미션은 삭제하지 않고 슬롯별로 보존 — 목표별 히스토리 노출의 원천 |
| ⬜ 테이블명 | DB 구조 개편 작업에서 확정 |

## 7. 표시 정책

| 항목 | 내용 |
| -- | -- |
| 게이지 | **미션 진척만 표시 · 숫자와 게이지 항상 일치**(55% 달성 = 게이지 55%) — 진척 외 제2의 의미 부여 금지 · 비선형 곡선 사용 금지 |
| 100% 도달 | 달성 연출 + 그 자리에 `새 미션 받기` 버튼 상시 노출 |
| 100% 초과 | 교체하지 않으면 실제 비율(140%·200% 등)을 계속 표시 · 교체 버튼도 함께 유지 · 표시 상한은 미결(§9) |
| 0% 상태 | 방치하지 않음 — 계산 방식 + 기록 필요성 안내 · 유산소는 기록 진입 버튼 직결 |
| 표현 상한 | "가슴 6세트분 — 권고 구간" 수준까지 · **"근육 N% 성장" 같은 효과 단정 금지** |

## 8. 검증

### 8-1. 출시 전

| # | 검증 | 방법 |
| -- | -- | -- |
| 1 | 미션 유형별 산식 | 유형 7종 각각에 대해 수동 계산값과 시스템 값 일치 |
| 2 | **미션 독립성** | 한 미션만 수행한 세션 입력 → 그 미션만 상승 · 나머지 값 변동 0 |
| 3 | 총량 인정 | 회당 기준 미달 실적(15분 × 12회) 입력 → 50% 산출 |
| 4 | 초과율 | 분자가 분모의 2배인 실적 입력 → 200% 표시 · 캡으로 잘리지 않음 |
| 5 | 교체 가능 판정 | 100% 도달 미션에만 교체 선택지 개방 · 미달 미션의 교체 요청 거부 |
| 6 | 부위 세트분 | 세부부위 복수 기여 운동 입력 → 1세트가 1.5세트분으로 계상 |
| 7 | 유산소 강도 환산 | 고강도 20분 입력 → 40분으로 계상 |
| 8 | 전량 재산출 멱등 | 같은 기록을 수정·삭제·재등록 → 최종 값이 항상 동일 |
| 9 | 목표·미션 독립 | 미션 0%에서 목표 완료 클릭 정상 처리 · 미션 전부 100%에서 목표 자동 완료 미발생 |
| 10 | 이력 | 미션 교체·목표 변경 후 이전 미션의 달성률 조회 가능 |
