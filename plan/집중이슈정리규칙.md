# 집중이슈 정리 규칙
계획을 모으는 문서가 아니라, **현재 가장 중요한 업무를 놓치지 않고 다음 행동으로 연결하는 통제판**이다.

## 사용 규칙

- `진행 중`은 원칙적으로 1개, 많아도 3개를 넘기지 않는다.
- 현재 집중 이슈에는 확인 가능한 완료 조건과 바로 시작할 수 있는 다음 행동이 있어야 한다.
- 세부 설계와 조사 내용은 `docs/`에 작성하고 여기에는 링크만 둔다.
- 이슈 상세는 작성하지 않고 Linear 링크로 대체한다.
- 세부 내용은 현재 집중하는 이슈만 한 줄로 표현한다.
- 매일 시작할 때 이 문서에서 하나를 골라 `daily/YYMMDD.md`로 옮긴다.
- 매일 종료할 때 결과와 다음 행동을 이 문서에 반영한다.

## 상태

| 상태 | 의미 |
| --- | --- |
| `진행 중` | 오늘 또는 가까운 시일 내에 직접 행동하고 있음 |
| `대기` | 외부 응답·권한·선행 작업을 기다리며 해소 행동과 재확인일이 있음 |
| `다음` | 중요하지만 현재 진행 중인 일 이후에 착수함 |
| `중단` | 지금은 하지 않기로 명시적으로 결정함 |
| `완료` | 완료 조건을 충족했고 결과가 남아 있음 |
