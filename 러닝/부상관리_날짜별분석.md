# 좌측 둔근 부상 — 날짜별 분석 및 보강 운동

> 근거: `몸상태.md` 부상일지 + FIT 데이터(2026-07-02, 07-10, 07-11).
> 데이터 기반 해석이며 의학적 진단이 아님. 물리치료 병행 중이므로 운동 추가/변경은 치료사와 확인 권장.

## 부상 패턴 요약

| 조건 | 통증 여부 |
|---|---|
| 지속 고강도 페이스 (4:20~4:50/km, 14km+ 또는 40분+) | **발생** (여수 25km→, 동계하프 14km→, 동아 7km→, 3/8 18km→) |
| 단거리 질주 (3:00/km ×3회) | 없음 |
| 저속 조깅 (6:00+/km) | 잔존기엔 통증 2~4, 회복기엔 없음 |
| 트레일/업다운 저강도 | 없음 (3/21, 6/13, 7/11) — 단 3월엔 볼륨 크면 사후 뻐근+회전 이상 (3/22) |
| 트레드밀 균일 지면 | 없음, 왼쪽 쏠림만 (3/10) |

**해석**: "일정 페이스를 오래 유지"할 때만 발생하는 부하 의존성 통증 → 좌측 중둔근~햄스트링 기시부의 **건병증(tendinopathy) 패턴**에 가깝다. 본인 추정(좌측 둔근이 회전 브레이크 역할로 과부하, 오른발은 버티는 스타일)과 정합적: 같은 착지를 수천 회 반복하는 로드 지속주가 최악의 조건이고, 부하 방향이 매번 바뀌는 트레일·단거리 질주는 견딘다. 3/10 트레드밀 "왼쪽 쏠림", 3/22 "외회전·내회전 비정상", 7/2 "피로 시 착지 불안정"이 모두 **좌측 고관절 회전 제어력 부족**을 가리킨다.

## 날짜별 분석

### 2026-01 발병기
- **01-05 남산 파틀렉 15km (업다운)**: 과부하 시작점. 속도 변화 + 언덕 = 둔근 이심성 부하 최대 조합.
- **01-06 고속 인터벌 중단 (둔부 근육통)**: 48시간 내 고강도 2연타로 급성 발현. *교훈: 고강도 세션 간 최소 48~72h.*
- **01-11 여수 풀 (통증 2→6, 감속 후 회복)**: 페이스를 낮추면 통증이 줄어드는 전형적 부하 의존성. 이미 손상된 조직으로 풀을 뛰어 만성화의 계기가 됨.
- **01-13 낮춘 인터벌도 소화 실패, 이후 반복**: 급성기에 스피드 재개가 빨랐음.
- **필요 보강 (발병기 기준)**: 통증 유발 없는 등척성부터 — ①사이드 브릿지 유지 30초×5, ②글루트 브릿지 등척성 45초×4, ③클램셸(밴드) 15×3. 러닝은 통증 2 이하 유지되는 페이스로만.

### 2026-02 잔존기
- **02-21 동계하프 (4:23 유지, 14km부터 통증)**: 임계 부하 확인 — **4:20~4:25 지속 약 60분**이 현재 조직 한계.
- **02-22~29 조깅 시리즈 (통증 1~4 등락)**: 6:00 이하 저속에도 통증이 남아있던 시기. 특히 02-24 물리치료 직후 업힐 조깅에서 불편감 → *치료 당일 업힐 자제.* 02-25 시작 전부터 통증4 → 전날 부하의 지연 반응, 하루 쉬는 게 나았음. 02-28 "신전 부위 불편"은 햄스트링 기시부 연관 신호.
- **필요 보강**: 등척성 유지 + 가벼운 근력 진입 — ①힙 하이크(pelvic drop) 12×3, ②밴드 사이드스텝 10m×4, ③싱글레그 글루트 브릿지 10×3. 조깅은 격일로, 통증 스코어가 전날보다 오르면 휴식.

### 2026-03 재발기
- **03-08 18km에서 재발 / 03-11 8.6km 7km 지점 통증2**: 거리 임계도 존재(약 7km부터 신호, 18km에서 한계). 조직이 아직 지속 부하 용량을 회복 못 함.
- **03-09 통증 조짐에 즉시 중단**: 좋은 판단. 이 원칙 유지.
- **03-10 트레드밀 무통 + 왼쪽 쏠림**: 지면 반력이 균일하면 무통 → 문제는 충격 자체가 아니라 **추진/회전 제어의 좌우 비대칭**.
- **03-15 동아 풀 3:14 (7km 통증1 → 25km 업힐 후 통증4, 완주 후 중둔근+햄기시 근육통)**: 업힐이 악화 트리거임을 확인. 손상 조직으로 풀 완주 — 기록은 지켰지만 회복 기간을 크게 늘림.
- **03-21 트레일 10.5km 무통 / 03-22 트레일 23.5km 후 회전 이상**: 다양한 부하는 견디지만 볼륨이 크면 회전 제어가 무너짐(외/내회전 비정상, 다리 들어올릴 때 통증2). SLR 계열 통증은 햄기시 자극 신호.
- **필요 보강**: 회전 제어 추가 — ①90/90 힙 로테이션 10×3, ②싱글레그 밸런스+상체 회전(맨몸→밴드) 30초×3, ③스텝다운(낮은 박스, 골반 수평 유지) 8×3, ④싱글레그 데드리프트 8×3. 업힐 지속주는 제외.

### 2026-04~07 회복·재건기 (FIT 데이터 있음)
- **04-25 KOREA 50K — 31.6km +2,337m DNF (위장장애, 둔근 무통)**
  데이터: 6:24:40, 평균 HR 132, 상승 블록 12개(최대 +296m). CP 휴식 직후 340~370분에 내리막을 HR 152~159로 강하게 내려감.
  - **둔근 관점에선 회복 근거의 시작점**: 6시간 이상, +2,337m, 피로 상태의 빠른 내리막까지 포함한 부하를 둔근 무통으로 소화. 3/22 회전 이상으로부터 약 한 달 만. (이후 6/13 아차산이 이를 재확인)
  - **DNF 원인은 위장**: 서울100(구토 DNF), 트랜스제주(위경련 3회) 에 이어 장시간 대회 GI 문제 3회째 — 둔근과 별개로, **울트라 대회의 실질적 제한 요인은 위장 관리**임을 시사. 보급 전략(섭취 종류·타이밍·강도 관리)은 별도 과제로 다룰 가치가 있음.
- **06-13 아차산 트레일 20km +1,005m (컨디션 좋음, 무통, 중간 버티컬 최대치 시도)**
  데이터: 2:53:28, 평균 HR 146(최고 190), 경사 8% 이상 구간 101개.
  **3/22(23.5km +830m 후 회전 이상·통증2)과 거의 같은 부하를 3개월 뒤 무통으로, 사후 이상 없이 소화** — 4/25 KOREA 50K에서 시작된 회복을 재확인. 컨디션 자평까지 좋았던 점에서 재건기 진입 판단의 확정점.
  참고: 이날 최고 심박 190 관측 → HRmax는 190 이상. 심박 존 계산 시 기준으로 사용 가능(순간 스파이크 가능성은 있음).
  - **버티컬 구간 확인: 129~142.5분, km 14.5~15.8 — 약 13.5분간 +203m** (본 등반 8.5분 +139m는 VAM 983m/h). 경사 20.6% 구간에서 HR 185 도달, 이 러닝의 사실상 최대 강도 지점.
  - **이후 피로 누적이 수치로 확인됨**: 같은 급경사 내리막(-8% 이하)에서 버티컬 전 HR 평균 140 → 후 157(+17bpm). 평탄 구간도 NGP 11:12→14:23으로 느려졌는데 HR은 141→147로 오히려 상승 — 출력 대비 심박이 안 떨어지는 전형적 피로 신호. 마지막 8분 내리막 마무리는 HR 179~185에서 4:11~4:45 페이스로 질주.
  - **부상 관리 관점 주의**: 버티컬 직후의 내리막은 "피로한 안정근 + 이심성 제동"이 겹치는, 좌측 둔근에 가장 위험한 조합 (7/2 착지 불안정과 같은 메커니즘). 이번엔 무통이었지만, **최대치 등반 후 내리막은 의도적으로 낮은 강도로 운영**할 것. HR 185로 급경사를 내려달리는 마무리는 재건기에는 피하는 게 안전.
- **07-02 보라매 업힐 인터벌 5km (무통, 착지 불안정으로 중단)**
  데이터: 질주 구간(20~23분) GCT 194ms / 보폭 121cm → 마지막 휴식 구간(23~24.5분) **GCT 248ms(+28%), 보폭 79cm(-35%), 수직비율 6.9→12.1%**. 통증보다 먼저 **신경근 피로에 의한 좌측 안정성 붕괴**가 온다는 걸 수치로 확인. 중단 판단이 정확했음.
- **07-10 여의도 로드 10.85km 템포 (통증 기록 없음)**
  데이터: 본 구간 34분간 GCT 206→211ms, 케이던스 90→88로 폼 저하가 미미. 4:45~5:05 페이스 36분을 폼 유지하며 소화 — **지속 부하 용량이 상당히 회복된 신호**. 단 이는 2월 통증 임계(4:23 지속)보다 느린 페이스라는 점 유의.
- **07-11 호암산 트레일 8.7km +468m (무통)**: 저강도(평균 HR 125) 파워하이킹 혼합. 둔근에 좋은 다각도 부하, 현 단계에 적합.
- **필요 보강**: 재건기 — 근력 볼륨 올리고 탄성 부하 진입. ①불가리안 스플릿 스쿼트 8×3(좌측은 템포 느리게), ②싱글레그 데드리프트 중량 추가, ③A-스킵/짧은 바운딩 20m×4, ④스트라이드(3:30~3:50) 100m×4 — 단거리는 원래 무통이므로 안전한 스피드 자극.

## 주간 보강 루틴 (현 단계)

| 요일 배치 | 내용 |
|---|---|
| 주 3회 (러닝 없는 날 또는 러닝 후) | 근력: 불가리안 스플릿 스쿼트, 싱글레그 데드리프트, 스텝다운, 밴드 사이드스텝 |
| 매일 5~10분 | 제어: 90/90 힙 로테이션, 싱글레그 밸런스+회전, 힙 하이크 |
| 고강도 러닝 전 | 활성화: 클램셸, 글루트 브릿지, A-스킵 |

**러닝 규칙**
1. 통증 3 이상 → 즉시 중단 (3/9처럼). 다음날 통증이 전날보다 오르면 휴식.
2. 지속주 페이스 상한을 단계적으로: 4:50 지속 40분 무통 2주 → 4:40 → 4:30. **4:2x 지속주는 마지막에.**
3. 고강도 세션 간 72시간 (1/5→1/6 재발 방지).
4. 업힐 "지속주"는 통증 재발 시 첫 번째로 제거. 트레일 저강도는 유지.
5. 7/2처럼 GCT가 질주 대비 +20% 이상 튀거나 보폭이 급감하면 그 세션은 종료 신호.

## 데이터 충분성 판단 (2026-07-12 기준)

- **보강 완료**: compact.csv에 러닝 다이내믹스 추가됨 — `gct_ms`(접지시간), `vo_mm`(수직진폭), `vr_pct`(수직비율), `step_cm`(보폭). 폼 붕괴 시점 탐지 가능해짐 (7/2 사례로 검증).
- **기기 한계**: **좌우 접지 균형(stance_time_balance)을 COROS 워치 단독으로는 기록하지 않음** (값이 0/비어 있음). 좌측 둔근 모니터링에 가장 직접적인 지표이므로, 원하면 COROS POD 착용 시 기록됨 — 파서는 이미 지원.
- **Suunto 기록 활동은 다이내믹스 미기록** (6/13 아차산, 7/11 호암산): Suunto 워치는 GCT/수직진폭을 기록하지 않음. 대신 경사도(`grade_pct`)와 경사 보정 페이스(`ngp`)가 있어 트레일 부하 분석에 사용. **GCT 등 폼 붕괴 지표 추적은 COROS 착용 러닝에서만 가능** — 기기 간 절대값 비교 금지.
- **기록 습관 요청**: FIT에는 통증이 없으므로 `몸상태.md`에 **통증 시작 km 지점(또는 경과 시간)과 통증 스코어**를 계속 기록해 주면 compact.csv의 해당 구간 다이내믹스와 대조해 "통증 직전 폼 변화" 패턴을 찾을 수 있음.
