## 종료 점검

- 반드시 끝낼 1개: `재계획` — 오늘 밤 집에서 이어서 진행
- 결과 또는 미완료 이유: CDC의 선행 작업인 S3 구조, binlog와 DMS 초기 IaC는 완료했지만 DMS CDC task 적용과 실제 복제 확인까지 끝내지 못했다.
- 중요 이슈 통제판에 반영한 다음 행동: 집에서 `feature/aws-dms`의 IaC 적용 상태를 확인하고 DMS endpoint 연결 테스트 → CDC task 시작 → 합성 운동기록 생성·변경 → S3 반영 확인 순서로 마무리한다.
- 문서화해 재사용할 내용: [Airflow·dbt 실행 위치 ADR](../../project/데이터자산화/airflow-클라우드위치-adr.md)과 [Lake 설계 메모](../../project/데이터자산화/lake설계.md)를 함께 커밋한다. CDC 검증 결과와 `load_type` 결정은 완료 후 보강한다.
- 우선순위를 바꿨다면 그 판단은 적절했는가: `적절`
- 다음에 같은 상황에서 적용할 기준: CDC 작업은 `원천 설정 / 인프라 생성 / 연결 테스트 / task 실행 / 데이터 검증`을 별도 체크포인트로 나눠 진행률과 막힌 지점을 기록한다.
