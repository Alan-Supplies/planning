# test-fly

REST client + SQL tools를 한 VSCode 확장에서 동시에 쓸 수 있는지 검증하는 스파이크.

## 가설
- `.http`(REST 요청)와 `.sql`(DB 쿼리) 실행을 **하나의 확장**으로 통합할 수 있다.
- 또는, 이미 그런 확장이 마켓플레이스에 존재한다.

## 성공 기준
- [ ] `.http` 파일에서 REST 요청을 보내고 응답을 확인
- [ ] `.sql` 파일에서 DB에 쿼리를 날리고 결과를 확인
- [ ] 위 둘을 **같은 확장(또는 조합)** 으로 전환 없이 사용

## 범위 밖
- 마켓플레이스 배포 / 등록
- 인증·권한 등 프로덕션 수준 완성도
- 다중 DB 드라이버 전부 지원

## 조사 대상 (후보)
- REST: `humao.rest-client`
- SQL: `mtxr.sqltools`
- 통합/대안: (조사하며 채움)

## 결론
> 검증이 끝나면 여기에 "가능 / 불가능 + 이유"를 기록한다.
