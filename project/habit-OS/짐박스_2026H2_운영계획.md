## 02 · STRATEGY

### 운동은 의지가 아닌 습관 — 시스템으로 설계 가능

**제품 비전** 운동 습관 운영체제(Habit OS) — 고객이 사는 것(몸·건강·인정·성취)은 전부 주 2~3회 꾸준한 운동을 요구. 앱이 아래 루프를 대신 운영한다.

**목표 → 일정 → 실행 → 기록 → 피드백&보상 → 반복** (순환)

**전략 1 — 계기(트리거)를 앱 밖에서 만든다**
습관 루프는 계기 없이 시작되지 않는데, 고객은 하루 대부분 앱 밖에 있다 — 온보딩에서 운동 요일·시간을 고정(환경 설계)하고, 스마트 알림이 "지금 가면 얻는 것"으로 트리거를 만든다.

**전략 2 — 세그먼트별 병목 제거로 '한 칸 이동'을 설계한다**

| 세그먼트 | 문제 | 해결 |
|---|---|---|
| 저→중 (17,914명) | **능력의 문제**: "오늘 뭘 하지" 결정 피로, 초보자의 막막함 | 마찰 제로 설계: 판단 0개(객관식·기본값) · 최소 탭 · 막히는 순간 원클릭 대안 |
| 중→고 (19,029명) | **동기의 문제**: 몸의 변화는 몇 주 뒤, 성장 실감 없음 | 즉시 피드백 설계: 몸이 변하기 전에 수치가 먼저 변하게(경험치·레벨·상위%) |
| 고방문층 (7,581명) | **이미 성공**: 새 기능이 아니라 퇴행이 리스크 | 비퇴행 원칙 + 손실 회피: 기존 동선 불편 금지, 쌓인 스트릭·기록이 이탈 방어벽 |

## 03 · USER JOURNEY — 7 CUTS

### 회원 A의 하루, 7컷

1. **계기** — "오늘 저녁 7시, 하체 플랜이 준비돼 있어요" (화요일 오후, 푸시가 먼저 부른다)
2. **시작** — G패스 원터치 (출석하면 운동 기록 유도)
3. **실행** — 오늘의 플랜(스쿼트 4세트 ✓, 레그 프레스 ✓, 런지 3세트, 20kg→15kg 바로 수정) — 완료 체크만으로 기록, 막히면 원클릭 대체
4. **보상** — 이두박근 Lv.3→Lv.4, 달성률 50%→75% (체크 즉시, 수치가 먼저 변한다 + 요약 이미지 도착)
5. **자랑** — G오더 쿠폰 도착 예정 전, #오운완 (인증 한 장이 비회원을 데려온다)
6. **실물 혜택** — G오더 쿠폰 ₦500 (한 달 주 2회 달성) (운동이 실제 보상으로까지 연동)
7. **재방문** — 운동 캘린더, 3주 연속 99% 경험치 (쌓이는 히스토리 — 확인 경쟁 구도 — 지속적인 운동)

### 고객 습관 형성의 핵심 — 피드백

| 여정 단계 | 회원 A에게 일어나는 일 | 장치 (아이템) | 작동하는 심리 기제 |
|---|---|---|---|
| ⓪ 설정 | 객관식으로 목표를 고르고("주 2회 운동"), 운동 요일·시간을 고정하고, 알림의 가치를 듣고 동의 | 온보딩 · 운동 목표(2단계 객관식) | 습관의 앵커 고정 — 실패하지 않는 목표 |
| ① 계기 | 화요일 오후, "오늘 저녁 7시 하체 플랜이 준비돼 있어요" 푸시 — 캘린더엔 오늘이 '할 날' | 예약 푸시 · 캘린더 · 스트릭 위기 알림 | 막연한 죄책감 → 구체적 계기 |
| ② 시작 | 앱을 열면 오늘 할 일이 이미 확정 — 플랜 불러오기 탭 1번, 입장은 G패스 원터치 | 운동 플랜 AI(3문항·주2회×4주) · G패스 탭 | 의사결정 0 — 시작 마찰 제거 |
| ③ 실행 | 항목별 완료 체크만으로 기록 — 기구 점유 시 원클릭 대체, 20kg이 무거우면 인라인 수정 | 운동 기록 2원화 · 기구 대체 · 인라인 수정 | 막히는 순간 0 — 흐름 유지 |
| ④ 보상 | 체크 즉시 경험치 적립, 이두박근 Lv.3→4, 달성률 50%→75%, 요약 이미지·응원 메시지 도착 | 레벨/랭킹 · 달성률 · 요약 이미지 V1 | 즉시 피드백 — 먼 보상을 오늘의 수치로 |
| ⑤ 자랑 | 인증샷에 연속 주차·운동 부위를 원버튼 합성해 #오운완 업로드 | 요약 이미지 V2(포토필터) · 뱃지 쇼케이스 | 인정 욕구 → 비회원 유입 |

루프 한 바퀴 = ① 습관 1회 강화(주 1회 → 주 2회 = 저→중 이동) ② 전 과정이 고객 ID 기준 데이터로 적재 — 2·3·4단계 기능의 원료. 코치마크·튜토리얼이 이 여정을 발견하게 만드는 입구.

### 화면 연결 구조도

**개발 순서**: 1-1 운동 기록 → 1-2 목표·스케줄·달성률 → 1-3 캘린더 → 1-4 요약 이미지 → 1-5 푸시 알림 → 1-6 코치마크 → 2 리디자인 → 3 히스토리·미션·둘러보기 → 4 PT+ 개편

- 붉은 카드 = 1단계(하반기 최우선) · 회색 = 2~4단계
- 실선 = 화면 이동(사용자가 이 화면에서 저 화면으로)
- 점선 = 데이터 공급(이 기능이 만든 데이터가 저 기능을 성립)

**온보딩** (진입 · 최초 1회)
- 1-2 운동 목표 설정 (객관식 2단계 · 건너뛰기 가능)
- 1-2 운동 스케줄 설정 (고정 요일·시간 = 약속 가시화)
- 1-6 코치마크 · 튜토리얼 (1단계 마지막 — 화면 확정 후)
→ 완료 시 홈으로 진입

**홈** (탭바 ① 홈, 나의 운동 현황을 전부 확인 — 앱의 허브)
- 1-2 운동 목표와 달성률 (목표 상시 노출 + 일 단위 달성률로 즉시 피드백)
- 1-3 캘린더 (1개월 단위 운동한 날 표시 · 날짜 클릭 → 그날 기록 상세)
- 3 미션 (개인화 운동 미션, 비정기 생성)
- 3 히스토리 (성장 곡선 · 상위% 리포트 · 부위별 인사이트·레벨·랭킹)

**운동 정보** (탭바 ⑤ 활동 → 신규, 챌린지·같이 운동하기와 동일 레벨 신규 메뉴)
- 1-1 운동 기록 (날짜별 상세 + 기록 버튼, 부위 기록 → 다음 운동 추천, 날짜 클릭 → 기록 상세로 진입)
- 1-4 요약 이미지 2종 (정보형 1장 + 셀피 필터, 기록 상세의 버튼으로 진입)
- 3 둘러보기 (비슷한·상위 레벨 회원의 최근 한 달 운동)

**PT+** (탭바 ⑥ PT+, 트레이너 앱 동반 개선)
- 4 PT+ · 트레이너 앱 개편 (수업 리포트 · 재수강 UX · 스마트 스케줄 · 매칭/추천 시스템)

**앱 전체** (전 화면 공통 레이어)
- 1-5 푸시 알림 (습관 형성에 필요한 타이밍에 가치 전달 메시지)
- 2 리디자인 (브랜드 디자인 가이드 기준 전체 퀄리티 상승)
- 3 G오더 쿠폰 (월 8회 출석 시 500원 할인 쿠폰 — 실물 보상)

연결 관계:
- 홈의 "기록 완료" → 홈에서 달성률·보상 확인
- 정체 감지 시 제안 → PT+ 진입

## 04 · PT REVENUE

### PT 매출 — 고객과 트레이너, 양면을 함께 잡는다

**고객**: "PT가 돈 값 한다" — 만족도·효용이 체감되어야 결제·재수강
**트레이너**: "짐박스가 수입 많고 일하기 편하다" — 좋은 트레이너가 모여야 고객 만족이 성립

**고객 만족 — "돈 값 한다"를 만드는 6가지**

1. 상담 리드타임 단축 — 신청부터 완료까지의 시간 단축 — 전환율 38%의 1차 병목
2. 재수강 원클릭 UX — 마음에 든 트레이너를 쉽게 재예약 — LTV 직결
3. 수업 기록 + 몸 변화 리포트 — 효용을 '느낌'이 아니라 데이터로 증명
4. 예약 시스템 개편 — 내가 트레이너·시간을 고른다 — 네이버 미용실 예약 벤치마크
5. 트레이너 정보의 '고객 언어' 번역 — 직관적 판단 가능 정보로
6. 데이터 기반 맞춤 매칭 — 몸 상태·운동 히스토리·목표를 종합해 트레이너 추천

**트레이너 만족 — 3가지**

1. 수업 캘린더 고도화 — 어느 지점·어떤 고객·몇 시 수업인지 한눈에
2. 고객 사전 분석 — '내 운동' 데이터로 수업 전 몸 상태 파악 → 첫 수업부터 전문적 처방
3. 커리큘럼 공유 → 자동 기록 루프 — 플랜을 미리 짜서 공유, 고객은 완료 체크만으로 기록·리포트

**전환 트리거**: 운동 데이터 축적 → 부위 정체·상위% 정체 감지 → 적시 제안("이두 성장이 멈췄어요") → 상담 전환 38→50% → PT Ratio 13%

### PT+ · 트레이너 정보 화면 재설계

자격증을 나열하는 화면에서, 짐박스 데이터로 '결과와 나와의 적합성'을 읽게 만드는 화면으로

**① 트레이너 리스트 - 순위가 아니라 매칭**
- "나에게 맞는 트레이너" — 강남점 · 내 목표: 여름 전 -5kg
- MATCHED FOR YOU — 너와 같은 목표 '여름 전 -5kg'를 이룬 회원이 담당한 트레이너부터 보여드려요
- 태그: 나의 비슷한 목표 · 체중감량 · 부상·통증 케어 · 근력
- 예시: 김도현(짐박스 검증) 체중감량·체력관리 특화, 최대 담당자 "체력이 다이어트" — 71% (3개월 체중감량 성공률) · -6.2kg (최대 감량 성공자) · 4.9 (평점 128명)
- 이수진(짐박스 검증) 부상·통증 케어 특화, 재활 후 복귀 프로그램 — 78% · 92% · 5.0
- 박준영(짐박스 검증) 근력·벌크업 특화, 초보자 자세 교정 세심 — 64% · +18kg · 4.8

**② 트레이너 프로필 - 검증된 성과가 먼저**
- 김도현 (✓짐박스 검증) — 체중감량·체력교정 강남점·경력 7년
- **짐박스가 검증한 성과**: 71% (3개월 재등록률, 지점 평균 52%보다 높음) · -6.2kg (담당 회원 평균 감량(12주), 지점 평균 4.1kg) · 89% (3개월 이상 지속 출석률, 업계 평균 60%대) · 4.9 (평점·후기 128명)
- **나와 비슷한 회원의 변화** (BEFORE/AFTER): 식단 7일↑ 이슈 -5kg 목표(12주 -6.2kg, 95% 달성) / 직장인 운동 경험 없음(16주 체지방 8%, 인바디 8주 완료) / 야간 운동 30대남(단기 근력 강화, 인바디 8주 완료)
- **자격·이게 나에게 뭘 의미하나**: 스포츠재활치료사 1급 — 통증 없이도 안전하게 운동 설계 가능 / 생활체육지도사 1급 — 초보자 자세 교정 부상 예방 강점 / 선수 출신·보디빌딩 입상 — 체형 대비·근육 분리감 강점

**핵심 포인트**
1. **프레임 전환** — "누가 최고냐"(순위) → "나에게 맞나"(매칭). PT 제안 설문의 목표·시작점을 그대로 정렬 기준으로 사용한다.
2. **자격증 → 결과** — 토익 900점처럼 바로 읽히는 숫자가 PT엔 없다. 그래서 짐박스가 만든다 — 재등록률 · 담당 회원 평균 성과를 전면에.
3. **플랫폼 해자** — 3개월 지속 출석률처럼 개별 트레이너는 만들 수 없는 신호를 1단계 운동 기록 데이터로 생성한다.
4. **나 대입** — 비포/애프터를 시작 체중·경험·라이프스타일로 태깅. 자격증은 "나에게 무슨 의미인지"로 번역해 보여준다.
5. **위험 제거** — 신뢰재는 틀려도 손해가 작아야 결정이 쉽다 — 무료 OT → 짧은 4주 계단 + "2주 안에 느껴질 변화"로 확신을 앞당김.

핵심 — 상담 전환율 38% → 50%의 병목은 "좋은 트레이너가 없다"가 아니라 "좋은지 알 방법이 없다". 판단 재료를 짐박스가 데이터로 제공한다.

## 05 · ROADMAP

### 4단계 로드맵 — 언제 무엇을

단계를 나눈 기준은 일정이 아니라 의존성 — 뒤 단계는 앞 단계가 만든 데이터 없이는 성립하지 않는다.

**타임라인 (2026 H2)**

- **1단계**: 근간 만들기 — 데이터·기능의 뼈대
- **2단계**: 전면 리디자인 + 탭바 개편
- **3단계**: 데이터 축적 후 가능한 기능 추가
- **4단계**: PT 개선 작업
- **병렬**: 데이터 자산화 — 단계마다 업데이트

| 단계 | 이 단계가 성립하려면 | 이 단계가 없으면 |
|---|---|---|
| 1단계 | 현행 앱 위에서 가능 | 2·3·4단계 전부 불가 (데이터가 없다) |
| 2단계 | 1단계의 기록·목표 데이터 | 레벨·상위%를 계산할 원천이 없다 |
| 3단계 | 1·2단계 배포 후 실제 축적된 데이터 | 인사이트·미션이 빈 껍데기가 된다 |
| 4단계 | 1~3단계의 운동 데이터 (부위별 히스토리·정체 신호) | PT 추천의 근거가 없다 |
