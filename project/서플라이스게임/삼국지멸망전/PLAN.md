# 삼국지멸망전 — 느슨 플랜

작성: 2026-09-02

## 전제 (확정된 조건)

- 개발 체제: 1인. 아트·사운드는 에셋스토어 구매 / AI 생성 / 무료 리소스로 조달.
- 투입 시간: 주 5시간 이하 (월 약 20시간, 연 약 250시간).
- 경험: Unity 처음, C#도 처음.
- 첫 목표: 전투 프로토타입 1맵.
- 최종 목표: Steam 출시.

## 현실 감각 먼저

연 250시간이다. 조조전/영걸전급 풀 캠페인(스테이지 40여 개, 무장 100명 이상, 시나리오 분기)은
1인 250시간으로 만들 수 없다. 유사 규모 인디 SRPG의 1인 개발 사례는 보통 수천 시간대다.

그래서 이 플랜의 목표는 "조조전 같은 게임"이 아니라 **조조전의 전투 규칙만 빌린 작은 SRPG**다.
스코프를 계속 깎을 축은 4개이고, 막힐 때마다 이 순서로 깎는다.

1. 스테이지 수
2. 무장 수
3. 시나리오 분기
4. 아트 물량

전투 규칙 자체는 깎지 않는다. 그게 이 게임의 전부이기 때문이다.

## 단계

### Phase 0 — 도구 익히기 (약 30시간 / 6주) → 상세: [PHASE0.md](./PHASE0.md)

목표는 "C#을 배운다"가 아니라 **클릭한 타일로 네모 하나가 움직이는 씬을 띄운다**이다.

- C# 최소치: 변수, 조건, 반복, 클래스, `List` / `Dictionary`. 문법책 완주는 하지 않는다.
- Unity 최소치: Scene / GameObject / Component / Prefab / Inspector, `MonoBehaviour`의 `Start`·`Update`, 씬 전환.
- 완전 초보 구간에서는 "필요할 때 검색"이 오히려 함정이다. 공식 Unity Essentials Pathway **1개만 끝까지** 완주하고, 그 다음부터 검색으로 전환한다.
- 2D로 확정한다. 1인 + 초보 + 아트 조달 난이도 모두 2D가 유리하다.

진입 판정: 10x10 격자를 그리고, 클릭한 칸으로 스프라이트 하나가 순간이동한다. 되면 Phase 1로.

### Phase 1 — 전투 프로토타입 1맵 (약 50시간 / 10주) ← 첫 목표

아트에 돈도 시간도 쓰지 않는다. 색깔 있는 네모와 숫자만으로 만든다.
이 단계의 유일한 질문은 **"이 전투가 재미있는가"** 이다.

- 1-1 그리드: 타일맵, 좌표계, 타일 선택
- 1-2 이동: 이동력 범위 표시(BFS), 경로 따라 이동
- 1-3 턴: 아군 3 / 적 3, 턴 순서, 행동 완료 처리
- 1-4 전투: 공격·피격, 데미지 공식 1개, 반격, 사망
- 1-5 병종 상성: 보병/기병/궁병 3종 + 지형 보정
- 1-6 적 AI: "가장 가까운 적" 또는 "가장 약한 적"을 노리는 수준

종료 판정: 이 맵을 내가 직접 세 번 연속 플레이했을 때 "한 판 더" 소리가 나오는가.
안 나오면 Phase 2로 넘어가지 말고, 요소를 하나씩(스킬 1개 → 진형 → 병력 수 개념) 붙여가며 다시 판정한다.
여기서 재미가 안 나오면 그 뒤 단계는 전부 헛수고다.

### Phase 2 — 게임의 껍데기 (재미 판정 통과 후)

- 저장/로드, 타이틀 화면, 스테이지 클리어 → 다음 스테이지 흐름
- 무장 성장(레벨·능력치), 전투 전후 화면
- 데이터 외부화: 무장·스테이지 수치를 코드에서 분리 (ScriptableObject 또는 CSV/JSON)
- **여기서 처음으로 아트를 교체한다.** 그 전까지는 네모다.

### Phase 3 — 데모 3스테이지 + Steam 페이지

- Steam 개발자 등록(수수료 약 $100), 스토어 페이지 심사 통과
- 데모 공개 → 위시리스트 수집 → "팔릴 물건인가" 1차 판정
- 판정 결과에 따라 Phase 4를 계속할지 여기서 멈출지 결정한다

### Phase 4 — 본편 확장 → 출시

Phase 3의 반응을 보고 그때 세운다. 지금 계획하지 않는다.

## 지금 정하지 않을 것

- "멸망전"의 컨셉 — 누가 멸망하는지, 오리지널 스토리인지. 전투 재미 판정과 무관하다.
- 시나리오 분량, 등장 무장 수, 판매 가격
- 멀티 언어 지원, 도전과제, 컨트롤러 지원

떠오르는 아이디어는 이 문서의 Icebox에 적고, Phase에 넣지 않는다.

## 리스크

- **학습 곡선 이탈** (가장 큼). 주 5시간이면 한 번 손 놓으면 복귀가 어렵다.
  대응: 매 세션 끝에 "돌아가는 것"을 남기고, 주 1회라도 커밋한다.
- **스코프 폭발**. 삼국지 소재는 아이디어가 무한히 나온다. 대응: Icebox로 보낸다.
- **아트 조달**.
  - 에셋스토어 리소스는 상업적 사용 가능 라이선스인지 구매 전 확인.
  - Steam은 AI 생성 콘텐츠 사용 시 등록 단계에서 신고(disclosure)를 요구한다. 정책은 바뀌므로 Phase 3 시점에 재확인.
- **삼국지 IP**. 원전 자체는 퍼블릭 도메인이지만, 코에이 게임의 무장 일러스트·고유 스킬명·UI를 그대로 가져오면 문제가 된다. 이름과 사서 기반 설정만 쓴다.
