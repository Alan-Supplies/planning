# Archive

종료된 과제의 산출물을 보관한다. **현재 진행 중인 문서는 여기 없다.**

## 규칙

- **그냥 던져 넣는다.** 이름은 원래 폴더·파일명 그대로. 하위 분류는 만들지 않는다.
- **날짜 접두어는 기본적으로 붙이지 않는다.** git 이 이미 알고 있는 정보다. 다음 두 경우에만 붙인다.
  - 같은 주제가 반복될 때 (예: `2026-07-테스트세션` — 세션은 또 열린다)
  - git 이력이 없을 때 (미추적 상태로 옮겨져 날짜를 알 방법이 없는 경우)
- 항목이 10개를 넘어 정렬이 아쉬워지면 그때 일괄로 날짜를 붙인다. 날짜는 `git log --format='%ad' --date=short -- <경로>` 로 조회한다.
- **기록은 사람이 쓰지 않는다.** 아카이브를 지시하면 AI 가 이 문서에 항목을 추가한다. 사람이 주는 정보는 "왜 끝났는지" 한 줄이면 된다.
- 종료됐어도 운영 중 계속 참조되는 문서(배포 절차, 컨벤션, 기준 문서)는 아카이브하지 않고 해당 Area에 남긴다.
- 기본적으로 검색·참조 대상이 아니다. 명시적으로 요청받았을 때만 읽는다.
