# Archive

종료된 과제의 산출물을 보관한다. **현재 진행 중인 문서는 여기 없다.**

## 규칙

- 폴더명은 `YYYY-MM-주제` — 종료 시점 기준. 하위 분류는 만들지 않는다.
- 종료됐어도 운영 중 계속 참조되는 문서(배포 절차, 컨벤션, 기준 문서)는 아카이브하지 않고 해당 Area에 남긴다.
- 기본적으로 검색·참조 대상이 아니다. 명시적으로 요청받았을 때만 읽는다.
