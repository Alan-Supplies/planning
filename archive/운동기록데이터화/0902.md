### 진행할 것
- 세트의 측정 정보
  count: 횟수
  weight: 무게 (kg만)
  duration_second: 시간 (러닝은 페이스 계산시 초가 기본)
  (현재 MINUTE으로 받고 있어서 서버 수정 필요)
- 운동종목(exercise)의 측정
  unit: SET / MINUTE (ASIS)
  weight_role (enum(LOAD / ASSIST)) // 어시스트 풀업은 ASSIST로 측정해서 부정으로 계산
- 유산소 강도는 피로도와 다른 개념으로 사용 할 수 있습니다.
  초기 마이그레이션에만 피로도 이용, 하지만 어떻게 쓸지 결정이 안된 상태라 나중에 진행하기로 결정했습니다.
- 운동 부위
  운동부위에 cardio와 stretching 은 포함하지 않는다.(지금은 원칙만 정한다.)
  exercise에 다음 컬럼 추가
  training_type
  enum('MUSCLE','CARDIO','STRETCHING') NOT NULL
